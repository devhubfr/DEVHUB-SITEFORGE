Documentation

Getting Started

DevHub SiteForge fonctionne entièrement dans votre navigateur : aucun compte, aucune API, aucun serveur. Choisissez un point de départ — un template, une description en langage naturel, ou une page blanche dans le Builder.

Créer son premier site

Depuis Templates, cliquez sur « Utiliser » sur un modèle proche de votre besoin, ou décrivez votre projet dans Générer par description. Vous arrivez directement dans le Builder avec une structure de départ.

Utiliser le Builder

La colonne de gauche liste les blocs disponibles (Navbar, Hero, Cards, Pricing, Galerie, FAQ, Formulaire, Footer, Texte, Image, Bouton). Cliquez sur un bloc pour l'ajouter en bas de page. La colonne de droite affiche les propriétés du bloc sélectionné dans la liste « Structure de la page ».

Ajouter une page

Dans le champ catégorie du projet, les pages détectées (Accueil, À propos, Contact, Tarifs…) sont générées automatiquement selon le template ou la description utilisée. Chaque page sélectionnée est exportée comme un fichier .html distinct dans le ZIP.

Ajouter une section

Cliquez sur un bloc dans la palette de gauche : il s'ajoute en bas de la page active et apparaît dans l'aperçu en direct ainsi que dans la liste « Structure ».

Modifier le CSS

Ouvrez l'onglet style.css dans l'éditeur de code, modifiez directement le texte, puis cliquez sur « Appliquer » pour recalculer l'aperçu avec votre CSS personnalisé.

Exporter

Le bouton « Télécharger ZIP » regroupe index.html, les pages additionnelles, css/style.css, js/script.js, un dossier assets/ et un README.md dans une archive prête à héberger.

Publier son site

Décompressez le ZIP et déposez son contenu chez n'importe quel hébergeur statique (Pages, Netlify, un serveur mutualisé…). Le site fonctionne sans dépendance serveur.
